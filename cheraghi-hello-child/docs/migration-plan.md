# برنامه مهاجرت از Enfold به Hello Elementor

## فاز ۱: آماده‌سازی امن

1. ساخت Staging از سایت فعلی در هاست.
2. نصب Hello Elementor و فعال‌سازی Elementor Pro.
3. نصب Child Theme اختصاصی `Cheraghi Hello Child`.
4. غیرفعال نکردن Enfold در سایت اصلی تا پایان تست.

## فاز ۲: نقشه لینک و پرداخت مشاوره

صفحات ضروری:

| نوع صفحه | آدرس پیشنهادی | هدف |
| --- | --- | --- |
| مشاوره | `/consultation/` | معرفی انواع مشاوره |
| مشاوره آنلاین | `/consultation/online/` | انتخاب، فرم و پرداخت آنلاین |
| مشاوره تلفنی | `/consultation/phone/` | انتخاب زمان، شماره تماس و پرداخت |
| تماس | `/contact/` | مسیرهای ارتباطی و نقشه |
| خدمات حقوقی | `/services/` | هاب خدمات حقوقی |

هر دکمه مشاوره باید به یکی از URLهای بالا وصل شود و بعد از پرداخت، کاربر به صفحه تشکر هدایت شود.

## فاز ۳: بازطراحی Elementor

1. طراحی Header مدرن با CTA ثابت مشاوره.
2. طراحی Hero صفحه اصلی با پیام روشن: وکیل پایه یک دادگستری، مشاوره تخصصی، دسترسی سریع.
3. طراحی بخش خدمات حقوقی با کارت‌های کوتاه و لینک داخلی.
4. طراحی بخش اعتمادسازی: سوابق، مجوزها، آکادمی، پرسش‌های پرتکرار.
5. طراحی Footer سبک با لینک‌های مهم، اطلاعات تماس و لینک مشاوره.

## فاز ۴: سئو تکنیکال

1. فقط یک H1 در هر صفحه.
2. استفاده از Schema مناسب: `LegalService`, `Person`, `LocalBusiness`, `FAQPage`, `Article`.
3. بررسی Sitemap و Robots.
4. ساخت ریدایرکت 301 برای URLهای تغییرکرده.
5. بررسی لینک‌های داخلی بعد از مهاجرت.

## فاز ۵: سرعت

1. حذف Enfold و افزونه‌های وابسته بعد از تایید کامل.
2. حذف اسلایدرهای سنگین.
3. فونت فارسی لوکال.
4. بهینه‌سازی تصاویر.
5. فعال‌سازی کش مناسب هاست.
6. تست PageSpeed و Lighthouse قبل و بعد از مهاجرت.
