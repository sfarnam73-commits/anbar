# تصاویر قالب

برای اینکه پیش‌نمایش دقیقاً شبیه طرح ارسالی شود، عکس پرتره دکتر فرزانه چراغی را با این نام داخل همین پوشه بگذارید:

```text
dr-cheraghi-portrait.png
```

مسیر نهایی باید این باشد:

```text
cheraghi-hello-child/assets/images/dr-cheraghi-portrait.png
```

اگر عکس JPG دارید، یا آن را به PNG تبدیل کنید، یا در فایل `preview/homepage-concept.html` مقدار `src` تصویر را از `.png` به `.jpg` تغییر دهید.
