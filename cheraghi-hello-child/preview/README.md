# لینک دیدن پیش‌نمایش

این محیط فایل‌ها را به‌صورت public روی اینترنت منتشر نمی‌کند؛ بنابراین تا وقتی پوشه قالب روی سایت یا هاست شما آپلود نشود، لینک اینترنتی واقعی وجود ندارد.

## بعد از آپلود روی سایت اصلی

اگر پوشه `cheraghi-hello-child` را در مسیر زیر آپلود کنید:

```text
wp-content/themes/cheraghi-hello-child/
```

پیش‌نمایش پیشنهادی با این لینک باز می‌شود:

```text
https://cheraghilaw.ir/wp-content/themes/cheraghi-hello-child/preview/homepage-concept.html
```

## اگر روی Staging آپلود کنید

لینک به همین شکل است، فقط دامنه Staging را جایگزین کنید:

```text
https://STAGING-DOMAIN.ir/wp-content/themes/cheraghi-hello-child/preview/homepage-concept.html
```

## اگر فایل‌ها را روی کامپیوتر خودتان دارید

فایل زیر را مستقیم با مرورگر باز کنید:

```text
cheraghi-hello-child/preview/homepage-concept.html
```

یا روی فایل دوبار کلیک کنید.

## نکته مهم

این فایل فقط برای دیدن طرح پیشنهادی است. نسخه نهایی باید داخل Elementor Pro با محتوای واقعی، لینک پرداخت واقعی و تنظیمات سئو ساخته شود.
