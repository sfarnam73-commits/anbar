# SOURCE GUARD

1. منبع اصلی سؤال را پیدا و متن سؤال/گزینه‌ها را عیناً استخراج کن.
2. شماره سؤال و درس را با نقشه دفترچه تطبیق بده.
3. کلید رسمی و اصلاحیه رسمی را جداگانه بررسی کن.
4. اگر هر بخش مبهم، ناقص یا متعارض است، خروجی `NEEDS_SOURCE_REVIEW` بده.
5. هیچ‌وقت برای پرکردن خلأ از حافظه یا حدس استفاده نکن.
6. خروجی موفق باید شامل این فیلدها باشد: question_no, subject, question_text, options[4], official_key, correction_status, source_refs.
