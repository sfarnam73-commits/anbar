# Cheraghi Academy V4

سامانه استاندارد تولید و کنترل مقالات آکادمی چراغی بر پایه Project + Skill + Plugins + n8n + WordPress.

## هدف
تبدیل دفترچه‌های آزمون وکالت به مقالات آموزشی چهار-سؤالی با دقت علمی، سئوی قوی، کنترل چندمرحله‌ای و قابلیت اتوماسیون.

## معماری
1. Project: حافظه، فایل‌ها، دستورهای ثابت و وضعیت پروژه.
2. Skill: روش ثابت تولید، تحلیل، کنترل و انتشار.
3. Plugins/Tools: Google Drive برای منبع، Semrush برای SEO، Canva برای تصویر، GitHub/Codex برای کد و نسخه‌ها.
4. n8n: هماهنگ‌کننده مراحل.
5. WordPress Bridge: دریافت Draft، Verify، Approve، Publish و Retry.

## قفل‌های کیفیت
- متن سؤال و گزینه‌ها فقط از منبع اصلی.
- عدم حدس پاسخ یا ماده قانونی.
- بررسی اصلاحیه و کلید رسمی.
- تحلیل چرایی پاسخ صحیح و رد گزینه‌های غلط.
- مثال ساده و دام تستی.
- بخش ثابت «نکته دکتر چراغی» برای هر سؤال.
- QC مستقل قبل از Final.
- انتشار پیش‌فرض به صورت Draft تا زمان تأیید.
